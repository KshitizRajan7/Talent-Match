# TalentMatch (Next.js)

Minimal README for the TalentMatch project.

**Overview:**
- A Next.js app for recruiter candidate management and search.

**Getting started:**
- Install dependencies: `npm install`
- Run in development: `npm run dev`
- Build: `npm run build`
- Start production: `npm run start`

**Key files & folders:**
- `src/app/` - Next.js app routes and UI
- `src/app/recruiter/` - Recruiter pages and components
- `src/app/recruiter/components/` - Candidate list, cards, filter sidebar
- `src/data/mockCandidates.ts` - Mock data used by the app
- `src/lib/api/candidates.ts` - API helpers for candidate data

**Notes:**
- The Updates block at the top highlights recent UI/UX placeholders and data-input improvements.

**Contributing / Next steps:**
- For changes to the UI, update components under `src/app/recruiter/` and adjust mock data in `src/data/`.
- Open an issue or PR with details and screenshots for visual changes.
